# Дуэль

Реализация проекта — Абеленцев Марк, РИЦП 251.

В этой консольной игре герой начинает с 20 HP и двумя зельями. У противника 24 HP. Вводите по одной команде на строку, заглавными буквами.

- `STATUS` показывает здоровье героя, здоровье противника и запас зелий.
- `ATTACK` наносит противнику 6 урона. Если он выжил, герой получает 5 урона в ответ.
- `HEAL` тратит зелье и восстанавливает до 8 HP, после чего противник наносит 5 урона. Когда зелья закончились, ход пропускается без ответного удара.
- `QUIT` завершает игру.

## Сборка

Выполните в корне проекта:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp Fighter.cpp Game.cpp -o game
```

В Windows запустите `.\game.exe`, в Linux — `./game`. В Visual Studio откройте `FightGame.sln` и нажмите Ctrl+F5. После запуска введите `STATUS`, чтобы увидеть начальное состояние.

## Классы

`Fighter` хранит текущее и максимальное здоровье одного бойца и ограничивает HP при уроне и лечении. `Game` содержит два объекта `Fighter`, хранит запас зелий и управляет порядком действий в бою.
